# Сайт SKVERNA

Публичные страницы клана и справочник SKVERNA OS 3.6.2. Сайт хранит статический экспорт Next.js для GitHub Pages: `index.html`, страницы в отдельных каталогах, файлы React Server Components `*.txt`, ресурсы `_next/` и `media/`. Исходный проект Next.js в этом репозитории отсутствует.

`/system/` знакомит с ботом, `/guide/` объясняет игровые механики, `/commands/` содержит 19 разделов и 381 строку справки, синхронизированных с `modules/commands/help.py` релиза 3.6.2. При изменении текста обновляйте и HTML, и соответствующие экспортированные `*.txt`, иначе переходы внутри сайта могут показать старый вариант. Полный актуальный справочник всегда доступен через `/commands` в Telegram. Модуль пересылки кастомок описан как подключаемая функция; источник @alliance_legion и тема Custom games уже указаны, используется авторизованная сессия новостей, после чего владелец включает пересылку.

`/miniapp/` — статический интерфейс Telegram Mini App (BIOFARM, составы, события, клановые цели). Он обращается к защищённому HTTPS API на Redmi; доступ проверяет сам бот по подписанным данным Telegram. GitHub Pages не хранит SQLite, токен бота, Telegram-сессии или пользовательские данные.
